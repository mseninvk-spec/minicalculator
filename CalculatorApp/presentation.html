System Objectives & Core Highlights

Delivering an intuitive, lightweight desktop application with zero third-party dependencies
⚡
Dual Interface Design
Offers two distinct user experiences:

  • CLI Mode: Lightweight, terminal-based interactive loop for terminal environments.
⌫
Precision Editing & Erase
Solves common typing mistakes without resetting state:
  • Single-Digit Erase (⌫): Backspaces the last typed digit sequentially.
  • Full Clear (C): Resets operands, operator, and history labels completely.

Full physical keyboard synchronization:
  • Type numbers directly from the Numpad or top row.
  • Operators (+, -, *, /, %) bound to matching keys.
  • Enter triggers calculation; Backspace erases a single digit.

Single-Digit Erase (⌫) Technical Implementation

Handling complex input boundary conditions, string mutations, and state synchronization
Backspace Logic (Calculator.java)
private void handleBackspace() { String text = displayField.getText(); // 1. Handle error state or zero if (text.startsWith("Error") || text.equals("0")) { displayField.setText("0"); startNewNumber = true; return; } // 2. Multi-character deletion if (text.length() > 1) { String next = text.substring(0, text.length() - 1); // If only negative sign or blank remains if (next.equals("-") || next.equals("-0")) { displayField.setText("0"); startNewNumber = true; } else { displayField.setText(next); startNewNumber = false; } } else { // 3. Single digit remaining -> reset to "0" displayField.setText("0"); startNewNumber = true; } }

Engineering Case Study 05 / 07

Cross-Version Compatibility Solution

Diagnosing and resolving Java Runtime version disparities across enterprise environments
⚠️
The Issue: Runtime Mismatch
When executing the app initially, a Windows error popup stated:
"A Java Exception has occurred."
UnsupportedClassVersionError: Calculator has been compiled by a more recent version of Java Runtime (class file version 65.0), this version only recognizes up to 52.0
  • Compiler (javac): Microsoft OpenJDK 21 (bytecode version 65)
  • Runtime (java): Oracle Java 8 on Windows PATH (bytecode version 52)
✓
The Engineering Solution
We implemented a permanent, multi-tiered cross-compatibility strategy:
Step 1: Target Bytecode Release
javac --release 8 Calculator.java
Forces the Java 21 compiler to emit clean Java 8 (version 52.0) bytecode.
Step 2: Smart Launcher Script
Updated run_gui.bat to autodetect modern JDK paths and fall back to the system environment safely.
